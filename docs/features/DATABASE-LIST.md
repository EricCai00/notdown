# List view

**English** · [简体中文](DATABASE-LIST.zh-CN.md)

List presents each page as a borderless row with its icon and title on the left and compact property values on the right. Values use their content width rather than equal table columns; empty values leave no placeholder. Long text is truncated unless wrapping is enabled. Click the title or row to open the record panel and edit its properties and body.

In **View settings → Property visibility**, search by property name, toggle properties in the shown/hidden sections, or use **Hide all / Show all**. The title always stays visible. Use the up/down buttons to change the order of shown properties. These settings belong to the current view and are saved on Done or dismissal; they do not delete properties or change another view. Failed saves retain the menu draft.

Filtering, sorting, grouping and New page continue to use the shared database records. Narrow views keep metadata within the row and truncate long values.
