# 知识库

[English](VAULTS.md) · **简体中文**

网页知识库管理器与桌面启动页共用一个选择界面。列表显示已知知识库，包括默认位置以外的文件夹，不移动其内容。当前网页知识库带有标记，不能从自身列表项重复打开。

选择 **新建知识库**，输入名称，检查表单下方显示的完整目标位置。**高级选项 → 父文件夹（仅用于此知识库）** 只覆盖本次创建位置，不修改默认设置。两种方式都会创建以知识库名称命名的子文件夹，拒绝覆盖已有文件夹。

选择 **打开已有知识库**，指定包含 `pages/` 的文件夹。桌面端提供系统文件夹选择器。网页路径指向运行 Notdown 服务的电脑，不一定是显示浏览器的电脑。网页可以打开新标签页；桌面启动页打开知识库窗口。

**默认保存位置 → 更改** 修改以后新建知识库的父文件夹。请选择已有、可写且本身不是知识库的文件夹。已有知识库仍登记在原位置，此操作不迁移笔记，也不改变当前打开的知识库。

Windows 全新安装使用系统实际的“文档”目录下的 `Notdown` 子文件夹。已有配置位置和包含知识库的旧目录继续使用。“文档”可能被 Windows 重定向，因此通过操作系统读取实际位置。应用的位置偏好单独保存在用户的本地应用数据目录。显式保存的位置优先于 `NOTDOWN_DATA_PATH`；`VAULT_PATH` 仍指定网页启动时的知识库。测试使用隔离配置与临时文件夹。

网页切换知识库前先保存待处理输入，保存冲突时停止切换并保留可恢复草稿。默认位置偏好不改写知识库文件。
