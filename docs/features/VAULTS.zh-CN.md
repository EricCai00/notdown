# 知识库

[English](VAULTS.md) · **简体中文**

网页知识库管理器与桌面启动页共用一个选择界面。列表显示已知知识库，包括默认位置以外的文件夹，不移动其内容。当前网页知识库带有标记，不能从自身列表项重复打开。

**新建知识库** 与 **打开已有知识库** 始终展开。创建时输入名称，通过 **浏览…** 或手动填写路径指定 **保存位置**，检查表单下方显示的完整目标位置。Notdown 会创建以知识库名称命名的子文件夹，拒绝覆盖已有文件夹。

**保存位置** 在首次输入或选择文件夹前为空。即使没有创建知识库就关闭窗口，也会记住上次输入，重启后继续显示。网页和桌面使用同一应用设置文件时共享这项偏好。它不会移动已有知识库或改变其内容。

打开已有知识库时，选择包含 `pages/` 的文件夹。两个路径字段都提供 **浏览…** 按钮。Windows 桌面版和网页版均使用带地址栏、导航侧栏及搜索的完整系统文件夹选择器；网页版通过本地 Notdown 服务打开，取消后保留原输入。其他平台的网页服务可手动输入路径。网页路径指向运行 Notdown 的电脑，浏览要求本机连接。网页可以打开新标签页；桌面启动页打开知识库窗口。

Windows 全新安装使用系统实际的“文档”目录下的 `Notdown` 子文件夹。已有配置位置和包含知识库的旧目录继续使用。“文档”可能被 Windows 重定向，因此通过操作系统读取实际位置。应用的位置偏好单独保存在用户的本地应用数据目录。显式保存的位置优先于 `NOTDOWN_DATA_PATH`；`VAULT_PATH` 仍指定网页启动时的知识库。测试使用隔离配置与临时文件夹。

网页切换知识库前先保存待处理输入，保存冲突时停止切换并保留可恢复草稿。位置偏好不改写知识库文件。

网页知识库地址采用 `/v/<id>/`。新地址取规范化文件夹路径（Windows 下转为小写）的 SHA-256 散列前 16 个十六进制字符。移动或重命名文件夹会改变地址，需要通过选择器重新打开。短标识若发生碰撞，会拒绝打开，而不会指向另一个知识库。这个 ID 是路由标识，不是访问令牌。

现有 64 位地址在文件夹路径不变时继续可用，包括页面／视图链接、API 请求和附件。应用校验完整散列，不自动跳转到短地址，以保留按旧 URL 存储的浏览器草稿。选择器的新入口使用短地址；知识库内不新增持久 ID 文件。
