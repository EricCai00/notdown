# 列表视图

[English](DATABASE-LIST.md) · **简体中文**

List 将每个页面显示为无边框的一行：左侧为图标和标题，右侧为紧凑的属性值。属性随内容宽度排列，不再使用等宽表格列，空值不占位。未启用换行时，长文本截断显示。点击标题或行可打开记录面板，编辑属性与正文。

在 **View settings → Property visibility** 中，可以按属性名称搜索，在显示／隐藏分区切换属性，或使用 **Hide all / Show all**。标题始终保留。上下按钮调整已显示属性的顺序。设置仅属于当前视图，点击 Done 或关闭菜单时保存，不删除属性，也不改变其他视图。保存失败时保留菜单草稿。

筛选、排序、分组和 New page 继续使用共享的数据库记录。窄屏下属性限制在行内，长值截断显示。
