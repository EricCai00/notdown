# GitHub 风格的警报验证

[English](GITHUB-ALERTS-2026-09-24.md) · **简体中文**

2026-09-24. 范围：现有编辑器中的外观、直接插入、可编辑标题、类型菜单、折叠和方言边界.

## 行为和来源

- 插入 GitHub 风格的警报会立即创建注释，而无需对话框。它的图标打开一个非模态菜单，其中包含彩色图标、可读名称和色样。同一菜单更改现有警报并启用可折叠。
- 标题内联编辑。编辑标题或打开图标菜单不会切换折叠。空心 V 形符号遵循标题：折叠时向右，展开时向下。
- [黑曜石标注文档 ](https://obsidian.md/help/callouts) 及其官方发布 CSS 和 JavaScript 已检查所有 27 关键字/别名、默认浅色主题颜色、Lucide 图标和 V 形放置/旋转。只有 Obsidian 和 Notdown 接受额外的关键字、自定义标题和折叠。其他启用警报的方言保留了五种基本类型；官方的 Notion 没有获得这些扩展。
- Notdown 保留 GitHub 颜色/Octicons 来表示“注释”、“提示”、“重要”、“警告”和“小心”。其他类型使用黑曜石颜色和图标。黑曜石配置文件自始至终都使用自己的调色板。未知类型保留其名称和来源；演示文稿配置文件是在不添加 Markdown 或 YAML 字段的情况下派生的。
