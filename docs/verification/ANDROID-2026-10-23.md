Try full browser regression first. When four independent temporary vaults are sharded in parallel, the available physical memory of the machine is reduced to approximately 75 MiB, and file read errors and assertion failures occur; sharding is stopped and the run is not recorded as a full pass.

Switch to single worker, independent port and build, and run 101 item checks related to saving, database, editor, navigation, page metadata, source code files, attachments, contacts and running environment: 91 passes, 10 fails. See `android-desktop-focused.log` for details.
