<a id="行为与保留规则"></a>

## Conduct and retention rules

- Wiki appears in Databases as a database, and the core constraint is a data source. Ordinary databases still support multiple sources; Wiki collection views hide source management and source switching.
- Home edits the original Markdown; All pages uses List by default, and other layouts reuse the existing collection view. Databases → New wiki creates the root layer Wiki, `/wiki` creates Wiki under the current page and inserts the existing official database reference or ordinary Markdown link.
- Page transitions inherit ID, file name, text, icon, attributes and parent location. Subpages retain nested relationships; the subdatabase and its records retain their original resource identities. Moving the subtree updates the Wiki membership.
- Undo only unblocks the Wiki container, field resources and views, retaining the text, page tree and per-page attribute values. The complete metadata before and after is saved in `.history/database-transactions/`, and there is no automatic recovery interface for archive configuration. The old imported standalone Home subpage continues to exist.
- Page/database versions must match; old window drafts cannot cross revision resulting from conversion. The transformation does not overwrite Markdown and conflicts retain the current version and proposal.

Notion official [ Wikis & verified pages ](https://www.notion.com/help/wikis-and-verified-pages) confirmation page transfers to Wiki and Undo Wiki, but does not fully specify how to save custom fields and views after Undo; the above is a clear local contract for Notdown.

## Validation boundaries

Notion is imported using simulated API, and the online end-to-end acceptance is not completed with real Wiki token; the mobile phone verification is a touch screen preview of Chrome, and the real machine acceptance of Android is not completed. Owner current user filtering, Verification workflows and notifications are not simulated. If the old Wiki data source has been shared by other databases, Undo will stop and reserve the resource.
