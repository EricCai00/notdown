## 范围

Android 0.1.4，版本号 5，在一台 Android 17 / API 37 真机上验证。APK 目标为 API 36，最低支持 API 26；本记录不代表所有支持的 Android 版本和厂商都已验收。

验收应用使用独立包名 `app.notdown.mobile.syncacceptance`、独立私有副本和 240 个合成页面。最终验证使用已有 HTTPS WebDAV 账号，在 `Notdown-checks/accept-*` 下创建独立临时知识库。源连接只读不改，正式知识库内容不作为测试数据。验收应用已允许通知，省电策略为无限制。

## 实现与验证

原生租约包裹现有共享 `synchronize` 会话，写入仍经过 `createVault`、版本校验及使用 `baseRevision` 的可恢复冲突处理。新同步在收取编辑器输入前后检查原生 Activity 暂停/恢复状态，不能仅凭息屏后仍可能报告文档可见的 WebView 判断；这个检查不取消当前同步。

只有 `GET` 和 `HEAD` 开启失效连接恢复，写请求继续关闭传输重试。没有新增定期后台任务、闹钟、开机重启或 `WorkManager` 集成。服务完成或失败后释放资源，另设 90 分钟安全时限，同时遵守 Android 服务超时。

自动化检查通过：Node 单元与服务测试 1300 通过（5 跳过）、手机浏览器测试 45 通过、原生 JVM 测试 13 通过，以及 TypeScript/应用构建、Android APK 构建和双语文档检查。原生测试覆盖失效读连接恢复、写请求不重放，以及取消后重新发起请求。

本次只验收一台已配置设备上已经开始的页面同步。强行停止、划掉任务、进程回收、服务额度耗尽、断网及厂商限制仍可能中断工作。大附件、长时间省电模式、网络漫游及其他厂商需要独立真机验收；现有游标、事务日志和持久上传队列恢复规则继续保留。
