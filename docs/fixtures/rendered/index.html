GFM 实际渲染对照

cmark-gfm（Python 绑定 2025.10.22）与 pandoc 3.11 / gfm。

实测：cmark-gfm 将有序任务渲染成复选框；Pandoc 3.11 / gfm 将其中的 [ ]、[x] 保留为文字。两者的无序任务均渲染为复选框。

官方直接说明：GitHub Markdown 速查表，第 2 页 TASK LISTS：“any unordered or ordered list supported”。GFM §5.3 对列表项统一定义任务标记，示例未单独展示有序任务。用户当前 Typora 截图中，有序任务保留文字，与这里的 Pandoc 结果一致。

渲染条件

两者均读取同一份 UTF-8 Markdown，未去掉 YAML，未调用 Notdown codec。cmark-gfm 开启原始 HTML 输出并使用自带 GFM 扩展；Pandoc 使用 gfm 输入格式。包装页限制活动内容，但保留各渲染器的 HTML 输出。数学、高亮、目录和图表等 Typora 扩展不在这里额外补齐。
